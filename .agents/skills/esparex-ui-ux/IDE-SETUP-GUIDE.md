## 📍 IDE SETUPS (Choose Yours)

### **SETUP #1: VS Code + Claude Extension** (RECOMMENDED)

#### Step 1: Install Claude Extension
```
1. Open VS Code
2. Go to: Extensions (Ctrl+Shift+X)
3. Search: "Claude" 
4. Click: Claude (by Anthropic)
5. Click: Install
6. Reload VS Code
```

#### Step 2: Sign In
```
1. Click Claude icon in left sidebar
2. Click: Sign in with Claude
3. Log in with your Anthropic account
4. You're in! ✓
```

#### Step 3: Create a New Chat
```
1. Claude sidebar → Click: "New Chat"
2. You're ready to use prompts
```

#### Step 4: Attach Design System Files
```
1. In Claude chat, look for: "+" or "Attach" button
2. Click to attach files
3. Select these 4 files:
   ✓ esparex-ui-ux-complete-skill.md
   ✓ HOW-TO-USE-THIS-SKILL.md
   ✓ QUICK-REFERENCE-CARD.md
   ✓ IDE-AI-PROMPTS.md
4. Click "Attach" or "Upload"
5. Wait for upload to complete ✓
```

#### Step 5: Copy & Use a Prompt
```
1. Open: IDE-AI-PROMPTS.md in VS Code
2. Find prompt you need (Prompt #1, #2, etc.)
3. Select all the text (Ctrl+A in prompt section)
4. Copy (Ctrl+C)
5. Go to Claude chat
6. Paste prompt (Ctrl+V)
7. Hit Enter
8. Claude responds using your design system ✓
```

#### Step 6: Use Claude's Response
```
AI gives you:
- Complete component code
- Explanations
- Design system references
- Testing steps

You can:
- Copy code directly to your file (Ctrl+C from Claude)
- Ask follow-up questions in same chat
- Keep files attached for next prompt
```

## 🎯 USING YOUR FIRST PROMPT

### Example: Build a Button Component

```
STEP 1: Make sure files are attached ✓
────────────────────────────────────

In VS Code + Claude:
- Look at chat → Should see file icons showing attached files
- If not attached: Click "+" again and attach

STEP 2: Open the Prompts file
─────────────────────────────

Open: IDE-AI-PROMPTS.md in VS Code
Find: "PROMPT #1: Build a Component"
Copy the whole prompt


STEP 3: Paste into Claude Chat
─────────────────────────────

1. Go to Claude chat panel
2. Click in chat input area
3. Paste the prompt (Ctrl+V)
4. Replace [BRACKETS] with your info:
   - [COMPONENT_TYPE] = Button
   - [DESCRIBE_YOUR_USE_CASE] = "Submit form button"
   - [LIST_YOUR_PROPS] = "onClick, disabled, loading, children"


STEP 4: Send the Prompt
──────────────────────

1. Click: Send (or press Enter)
2. Claude reads your attached skill files
3. Claude generates button component code
4. Wait for response (usually 10-30 seconds)


STEP 5: Copy Claude's Code
──────────────────────────

Claude's response will include:
- Complete React/TSX component code
- Semantic tokens used
- A11y features included
- Comments explaining each choice

Copy it:
1. Click: "Copy" button in Claude chat
   OR
2. Select code → Ctrl+C


STEP 6: Paste into Your Project
───────────────────────────────

1. Open your component file (e.g., Button.tsx)
2. Paste the code (Ctrl+V)
3. Adjust if needed (import paths, etc.)
4. Save file (Ctrl+S)
5. Done! ✓


STEP 7: If You Need Changes
──────────────────────────

In same Claude chat:
- Ask: "Add a loading state"
- Ask: "Make it responsive for mobile"
- Ask: "Add error state"
- Ask: "How do I test this with axe DevTools?"

Claude responds with updates
You copy → paste → done ✓
```

## 🆘 TROUBLESHOOTING

### Issue: "Files aren't showing in Claude"

**Solution:**
```
1. Check that files are actually attached
   → Look for file icons in chat area
2. Re-attach if needed:
   → Click "+" button
   → Select all 4 files again
   → Wait for upload to complete
3. Try new chat:
   → Close current chat
   → Click "New Chat"
   → Attach files
   → Try prompt again
```

---

### Issue: "Claude isn't using the design system"

**Solution:**
```
1. Check prompt mentions "attached design system files"
   → If prompt doesn't say it, add this to beginning:
   "Using the attached design system files..."

2. Re-attach files:
   → Remove attachment
   → Re-attach all 4 files
   → Wait for confirmation

3. Try referencing specific file:
   → "Based on esparex-ui-ux-complete-skill.md..."
   → "According to QUICK-REFERENCE-CARD.md..."
```

---

### Issue: "Code doesn't match design system"

**Solution:**
```
1. Ask Claude to review:
   - Use Prompt #10 (Complete Compliance Check)
   - Paste your code
   - Claude will identify issues

2. Ask Claude to fix:
   - Use Prompt #14 (Quick Fix)
   - Paste your code + reviewer comment
   - Claude fixes it

3. Use axe DevTools:
   - Right-click → "Scan page with axe"
   - See actual errors
   - Ask Claude to fix each one
```

---

### Issue: "AI responses are generic, not design system specific"

**Solution:**
```
1. Make sure files are attached (see above)
2. In prompt, explicitly reference files:
   "Based on the attached esparex-ui-ux-complete-skill.md..."
3. Include specific section name:
   "Using Rule #1 from the skill file..."
4. Ask follow-up:
   "Refer to the WCAG 2.2 AA checklist in the skill"
```

---

### Issue: "Can't find the attach button"

**Solution - Different IDEs:**

```
VS Code + Claude:
→ Look for "+" or attachment icon in chat input area
→ Or right-click → "Attach files"

GitHub Copilot:
→ Click "+" button
→ Select "Attach files"

Cursor:
→ Drag & drop files into chat
→ Or click "+" 

JetBrains:
→ Look for attachment icon in AI chat panel
→ Check: Tools → AI → Settings
```

## 🎓 BEST PRACTICES

### 1. Keep Files Attached
```
DON'T:
- Close and re-open chat
- Remove files between prompts
- Start new chat for each prompt

DO:
- Keep same chat open
- Files stay attached
- Use one chat for multiple prompts
- All context is preserved
```

---

### 2. Ask Follow-Up Questions
```
First prompt:
"Build a button component"
→ Claude builds it

Follow-up:
"Add a loading state"
→ Claude updates it

Follow-up:
"Make it responsive"
→ Claude updates again

All in same chat, files attached the whole time ✓
```

---

### 3. Be Specific
```
VAGUE:
"Make me a component"
→ Claude guesses what you want

SPECIFIC:
"Build a primary action button for a form submission
that shows loading state while submitting"
→ Claude knows exactly what you need
```

---

### 4. Reference Specific Sections
```
WEAK:
"Follow the design system"

STRONG:
"Follow Rule #1 (semantic tokens) and Rule #6 (WCAG 2.2 AA)
from esparex-ui-ux-complete-skill.md"

Claude will be more precise
```

---

### 5. Save Good Prompts
```
If you create a great custom prompt:
1. Copy it
2. Save in a file: my-prompts.md
3. Reuse for similar tasks
4. Build your own prompt library
```
