# Security Policy

## Reporting a Vulnerability

Esparex takes security seriously. If you discover a vulnerability or potential security issue in any package or application within this monorepo, please report it immediately.

**Do NOT report security vulnerabilities through public GitHub issues.**

### Reporting Procedure

1. Email our security team directly at `security@esparex.in`.
2. Include full details of the vulnerability, steps to reproduce, and any proof-of-concept code.
3. We will acknowledge receipt of your vulnerability report within 24 hours.

### Security Updates & Responsible Disclosure

* We commit to investigating and patching critical vulnerabilities within 72 hours.
* We request that reporters maintain confidentiality until a patch has been released.
* Security advisories will be published on our security portal upon patch release.
